SmallOLED test build for the WiFi setup fix.beta

This is a pre-release build made to fix a WiFi problem on some ESP32-C3 boards, where the PCMonitor-Setup network never showed up. Flash it, try the WiFi setup, and let me know if it works.

This is a test build, not the official release. It exists to confirm a fix before it ships to everyone. If your board already works fine, stay on the stable flasher. Your saved settings are erased during install, so you'll set up WiFi again.
Open this page on desktop Chrome or Edge. Flashing uses Web Serial, which only runs on a desktop Chromium browser.
01

Flash the test build

chip
ESP32-C3
display
SSD1306 · 128×64
firmware

flash
0x0 · full image (bootloader + app)

Plug the board in over USB first. A dialog asks which serial port to use - pick the one that appears when you plug in. The installer erases and writes the full image at 0x0; it takes ~30 seconds. If it won't connect, hold BOOT, plug in USB while holding, then release.

02

Connect to WiFi

This is the part the fix is about - please test both the in-tab setup and the setup hotspot if you can. Either way the device reboots onto your WiFi and shows its IP address on the OLED.

recommended

Configure WiFi in this tab

When the flash finishes, the install dialog opens a Configure WiFi step. Pick your home network, type the password, hit Connect. Credentials travel over USB - no app, no captive portal. It appears only on a freshly flashed device, for about 3 minutes.

the fix

Or join the setup hotspot

This is the network that was invisible before. After flashing, look for a WiFi network called PCMonitor-Setup on your phone or laptop - this is what should now appear.

setup-mode access point
network PCMonitor-Setup
open http://192.168.4.1

No password. Join it, open 192.168.4.1, pick your home network, save. The device reboots and shows its IP on the OLED.

03

Send logs back

If something still goes wrong, this captures the board's boot log so I can see exactly what happened. Plug the board in over USB, click Connect, pick the same serial port you flashed with, then let it boot. Use Export to save the log and attach it to the issue.



          
Only one program can hold the serial port at a time - don't click Install during a monitor session. Baud rate is 115200.
